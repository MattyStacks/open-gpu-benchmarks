Get the data as JSON

Every number on this page comes from static JSON files built from the reviewed YAML. Use them in scripts, spreadsheets, or your own charts. No key or sign-up needed.

dashboard.json

The grouped official and community summaries behind this chart, plus the game, resolution, and preset lists.

gpus.json

The GPU catalog with full hardware specs, each GPU's official and community summaries, and links to its per-GPU files.

official.json

Every official run, one record per resolution and preset profile.

community.json

Grouped community summaries, with the exact machine details and GitHub submitter for each run.

<source>/<gpu_id>/summary.json

One GPU's runs and summaries, for example official/rtx_4090_24gb_fe or community/steam_deck_oled_16gb. GPU IDs are listed in gpus.json.

Contribute benchmark evidence

How community submissions work

Exact machine runs in; clean, comparable GPU summaries out.

Use a pull request to submit a run. The validator checks the profile and a maintainer reviews the evidence before it is included.
</>

Fork and prepare

Fork the repository and use the submission template as a starting point.

+

Add profiles

Create result_YYYYMMDD_<game>_<github_user>.yaml in data/community/<gpu_id>/, set submitted_by to your GitHub username, and add each resolution/preset as a dashed result entry.

✓

Validate locally

Run the build and validator before opening your pull request.

⌕

Review evidence

Maintainers check the capture, profile, machine details, and significant outliers.

↗

Approve and group

Merged runs are grouped into generated summaries for that GPU.

Ready to contribute? Copy the submission template, choose your GPU result folder, then follow the contribution guide.

Community YAML example

# data/community/rtx_4070_super_12gb_fe/result_20261003_cyberpunk_mattystacks.yaml
gpu_id: rtx_4070_super_12gb_fe # catalog file name in data/gpus/
submitted_by: MattyStacks # your GitHub username
benchmark_type: game
game: Cyberpunk 2077
frame_generation: false
form_factor: desktop
device_name: Ryzen 7 7800X3D test bench
gpu_power_w: 220
overclocked: false
result:
  - resolution: 1440p
    graphics_preset: Ultra RT
    upscaling: DLSS Quality
    avg_fps: 79.1
    p1_low: 65.0
  - resolution: 1080p
    graphics_preset: Ultra RT
    avg_fps: 103.4
    p1_low: 84.7
system:
  cpu: AMD Ryzen 7 7800X3D
  memory: 32 GB DDR5
  power_mode: Performance
  driver: "561.09"
proof:
  raw_log: raw/cyberpunk_1440p.csv

Review checklist

Required

  • GitHub username in submitted_by and the file name
  • GPU and form factor
  • Game, resolution, and settings
  • Avg FPS and 1% low
  • Frame generation off
  • Evidence reference

Strongly encouraged

  • Raw PresentMon capture
  • Laptop TGP or GPU power
  • Exact card or device name
  • CPU, memory, and power mode
  • Driver and display mode

Validate every profile: the leading dash makes result a YAML list. Every profile is checked independently and only matching GPU, power, game, resolution, and preset entries are averaged. A submission more than 50% away from a matching official baseline must be corrected, explained by a different profile, or removed during review.

Desktop and laptop GPUs never share a group. Game version remains as metadata, while matching summaries use GPU, form factor, known power profile, game, resolution, and graphics settings.
